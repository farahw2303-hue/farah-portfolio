PROJECT OVERVIEW

About the Project

The Student Performance Analytics Dashboard for Educational Decision-Making is an interactive Power BI project developed to analyse student academic performance and the factors associated with it.

The dashboard uses a dataset containing 6,607 student records and 20 original variables, including exam scores, attendance, study hours, motivation levels, family background, school type and academic support status.

The project consists of six dashboard pages: Home, Management, Student View, Elderly-Friendly View, Advanced Analytics and Project Timeline. Different dashboard views were designed to make the information suitable for different users such as students, teachers, parents, counsellors and school administrators.

Data cleaning and transformation were performed using Power Query, while DAX was used to create measures such as total students, average exam score, pass percentage, average attendance, average study hours and students requiring academic support.

Interactive features including filters, slicers, tooltips, cross-filtering, drill-down analysis and page navigation allow users to explore student-performance patterns and identify students who may require additional academic support.
