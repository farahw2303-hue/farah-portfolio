PROJECT OVERVIEW

About the Project

The Interactive Retail Sales & Profit Performance Dashboard was developed to transform retail data into a more accessible and interactive analytical experience.

The dashboard allows users to explore key business indicators related to sales, profit, product performance and overall retail performance through interactive charts and KPI visualizations.

The interface was built using HTML and CSS, while JavaScript was used to manage dashboard behaviour and data interaction. D3.js was used to generate dynamic data visualizations that respond to user interaction.

The completed project was deployed using GitHub Pages, allowing users to access and interact with the dashboard directly through a web browser.

DASHBOARD FEATURES

Key Features

Sales Performance Analysis

Provides visual analysis of retail sales performance to help users identify overall patterns and changes in business activity.

Profit Analysis

Displays profit-related information to support comparison between sales performance and business profitability.

Product Performance

Enables users to compare product performance and identify products contributing strongly or weakly to overall business results.

Interactive Visualizations

Uses D3.js to create dynamic charts and visual interactions that allow users to explore the dataset more effectively.

Business KPIs

Presents important performance indicators in a clear dashboard layout for faster interpretation of retail performance.

Web-Based Access

Deployed through GitHub Pages so the dashboard can be accessed directly from a browser without requiring additional software.
