PROJECT OVERVIEW

About the Project

The Job Market Data ETL Pipeline is a data engineering project built using a real-world job-posting dataset sourced from Kaggle.

The original dataset contained 19,649 job-posting records across six fields including job titles, company names, experience requirements, package information, locations and skills.

The project implements a complete Extract, Transform and Load workflow using Python and Pandas. Raw records are inspected, cleaned, transformed and validated before being loaded into a structured SQLite database.

The completed pipeline produced 19,521 cleaned records and 23 transformed columns, which were then analysed using SQL to identify patterns in skills demand, hiring locations, companies, experience requirements and remote opportunities.

ETL WORKFLOW

Pipeline Process

1. Extract

Reads the raw Kaggle CSV containing 19,649 job-posting records and validates the expected dataset structure before processing begins.

2. Transform

Cleans missing values, removes duplicates, standardizes column names, parses experience requirements and creates new analytical fields.

3. Load

Loads 19,521 cleaned records into a SQLite database and creates indexes for commonly queried fields such as job ID, title, company and location.

4. SQL Analysis

Executes analytical SQL queries to explore technical skill demand, hiring locations, companies, experience requirements, remote opportunities and package disclosure.

DATA QUALITY

Cleaning & Transformation

  • Identified missing values across job titles, company names, experience, package, locations and skills.
  • Removed 3 exact duplicate records.
  • Removed records missing essential job-title or company information.
  • Converted original column names into consistent snake_case naming.
  • Parsed experience ranges into minimum and maximum years.
  • Extracted primary locations from multi-location job postings.
  • Created technology-skill indicators for Python, SQL, Power BI, Excel, Tableau, Machine Learning and ETL.
  • Added validation checks to ensure the number of records loaded into SQLite matched the transformed dataset.

SQL ANALYSIS

Key Findings

SQL

SQL was the most frequently detected selected technical skill, appearing in 3,595 job postings.

Machine Learning

Machine Learning appeared in 2,691 job postings, making it another frequently identified skill.

Python

Python was detected in 1,618 job postings, while 743 postings contained both Python and SQL.

Top Location

Bangalore/Bengaluru recorded the highest number of primary-location job postings with 4,035 records.

Remote Opportunities

The SQL analysis identified 1,044 postings containing remote opportunities, representing approximately 5.35% of the dataset.

Package Disclosure

Approximately 91.07% of job postings did not disclose package information.

IMPLEMENTATION

Project Structure

  • extract.py — reads and validates the source dataset.
  • transform.py — performs data cleaning, transformation and feature engineering.
  • load.py — loads transformed records into SQLite and validates the database.
  • pipeline.py — runs the complete ETL process using a single command.
  • analysis.sql — contains SQL queries used to analyse the cleaned data.
  • run_analysis.py — executes and displays the SQL analysis results.
